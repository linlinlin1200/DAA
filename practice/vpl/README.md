# Programming Lab Practice

These five standalone programs correspond to the recursion and pattern problems shown in the course. Run any file with Python 3 and provide input on standard input. No files were sent to the OCS judge.

1. Recursion 1 prints each successive suffix. The final suffix is empty, so its last output line is blank. Printing all suffixes takes Θ(n²) characters.
2. Character Patterns 1 prints a checkerboard using the parity of row plus column.
3. Character Patterns 2 prints stars on the border and dots in the interior. Each pattern takes Θ(rows × columns) time.
4. Divisibility visits only multiples of x below n and omits multiples of y and the number 1.
5. Recursive Power computes the half power once and squares it. It takes O(log |n|) multiplications for nonzero n and handles negative integer exponents by taking the reciprocal.
