# 111. Minimum Depth of Binary Tree

[Условие на LeetCode](https://leetcode.com/problems/minimum-depth-of-binary-tree/)

## 1. Problem

Нужно найти число узлов на самом коротком пути от корня до листа. Лист — узел без обоих детей. Пустое дерево имеет глубину `0`.

## 2. Approach

Используется обход по уровням, BFS. В очередь сначала помещается корень. Перед обработкой уровня запоминается число узлов в очереди, чтобы добавленные дети относились уже к следующему уровню.

Как только встречается лист, возвращается номер его уровня. Все более близкие к корню узлы уже просмотрены, поэтому более короткого пути до листа нет. Итеративный обход также работает на длинных цепочках без рекурсии.

Пример: `[3, 9, 20, null, null, 15, 7]`.

| Шаг | Очередь | Действие |
| --- | --- | --- |
| 1 | `[3]` | Начинаем уровень 1 |
| 2 | `[9, 20]` | У `3` есть дети, добавляем их |
| 3 | `[9, 20]` | Начинаем уровень 2 |
| 4 | `[20]` | Узел `9` — лист, возвращаем `2` |

Основная сложность — не принять отсутствующего ребёнка за лист. Формула `1 + min(глубина слева, глубина справа)` без дополнительных условий ошибочна: для `[1, null, 2]` она даёт `1`, хотя путь до единственного листа содержит два узла. Этот неудачный вариант отдельно проверяется в тестах.

## 3. Time Complexity

**Время: O(n)** в худшем случае, где `n` — число узлов. Каждый просмотренный узел один раз добавляется в очередь и один раз извлекается. На цепочке придётся дойти до самого конца. Если корень — лист, достаточно O(1).

**Дополнительная память: O(w)**, где `w` — максимальная ширина дерева. В очереди могут одновременно находиться остаток текущего и начало следующего уровня; их суммарный размер O(w). В худшем случае память O(n), а на цепочке — O(1).

## 4. Reflection / Improvement

BFS уже позволяет завершить обход на ближайшем листе. Лучше O(n) в худшем случае не получится: в цепочке нужно найти её конец. DFS с правильной обработкой единственного ребёнка использует O(h) памяти, но может потратить время на длинную ветку до обнаружения короткой.

В тестах есть пустое дерево, одиночный лист, односторонние деревья, ближайший лист рядом с длинной веткой, цепочки из 100 000 узлов и 300 случайных деревьев. Для случайных деревьев используется независимая рекурсивная проверка. Это локальные тесты, а не отправка в LeetCode.
