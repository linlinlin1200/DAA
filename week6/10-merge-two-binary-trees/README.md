# 617. Merge Two Binary Trees

[Задача на LeetCode](https://leetcode.com/problems/merge-two-binary-trees/)

## 1. Problem

Нужно объединить два дерева по одинаковым позициям. Если узел есть в обоих деревьях, складываю значения. Если только в одном — сохраняю его значение и ветки.

## 2. Approach

Создаю новое дерево. В стек кладу тройку: узел первого дерева, узел второго и соответствующий узел результата. Для левых и правых детей отдельно проверяю, есть ли хотя бы один узел. Если есть, создаю ребёнка результата и добавляю следующую тройку в стек. Отсутствующий узел даёт слагаемое `0`.

Для `[1,3,2,5]` и `[2,1,3,null,4,null,7]`:

1. Корни: `1 + 2 = 3`.
2. Левые дети: `3 + 1 = 4`.
3. Правые дети: `2 + 3 = 5`.
4. Ниже остаются узлы `5`, `4` и `7`, у которых нет пары.
5. Результат: `[3,4,5,5,4,null,7]`.

Основная сложность — сохранить ветку, когда во втором дереве на её месте `null`. Обход только общих узлов теряет такие ветки: например, `[1]` и `[1,2]` должны дать `[2,2]`. Этот случай есть в тестах. Также проверены пустые деревья, отрицательные числа и длинные цепочки. Дополнительно проверяется, что входные деревья не изменились и их узлы не используются в результате.

## 3. Time Complexity

**Time Complexity: O(n₁ + n₂)**. Каждый существующий узел входных деревьев обрабатывается один раз, а создание соответствующего узла результата занимает постоянное время.

**Space Complexity:** `O(h)` для стека, где `h` — максимальная высота входных деревьев. Само новое дерево занимает `O(u)`, где `u` — число позиций, занятых хотя бы в одном дереве. Поэтому общая дополнительная память вместе с результатом — `O(h + u)`.

## 4. Reflection / Improvement

Можно изменять первое дерево и присоединять готовые ветки второго. Тогда потребуется меньше новых объектов, но результат будет связан с исходными данными. Здесь выбрано отдельное дерево. Для независимого результата время `O(n₁ + n₂)` улучшить нельзя: все его узлы нужно создать.
